# ArthoPulse Dashboard

**Smart Finance, Smarter Future.**

ArthoPulse combines *Artho* (অর্থ) and *Pulse* (স্পন্দন) — a clearer pulse on your finances.

Standalone React/Vite project for the ArthoPulse fintech dashboard.

## Design system

An import-ready visual reference board is available at [design/ArthoPulse-Design-System.svg](./design/ArthoPulse-Design-System.svg). In Figma, import or drag the SVG onto the **Design system** page. Its color swatches, type scale, spacing, surfaces, and UI examples can then be used as editable reference artwork.

## Run locally

```sh
npm install
npm run dev
```

## Validate

```sh
npm run lint
npm run build
```
