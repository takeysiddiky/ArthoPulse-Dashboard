# ArthoPulse Dashboard

**Smart Finance, Smarter Future.**

ArthoPulse combines *Artho* (অর্থ) and *Pulse* (স্পন্দন) — a clearer pulse on your finances.

Standalone React/Vite project for the ArthoPulse fintech dashboard.

## Run locally

```sh
npm install
npm run dev
```

## Validate

```sh
npm run lint
npm run build
```
